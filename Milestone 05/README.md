## Python Files
Before running any of the files, install the dependencies first and make sure ROS2 is sourced in the terminal:
```pip install -r requirements.txt```

```final_simulation.py``` moves the robot from its resting position to the initial position, and cuts out a batman symbol.
```batman.py``` shows the position task trajectory of the batman symbol
```circle.py``` shows a position task trajectory for a circle
